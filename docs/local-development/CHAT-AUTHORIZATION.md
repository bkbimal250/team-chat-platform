# Chat authorization — current boundaries

Workspace Conversation, Messaging, Realtime and Media require organization/member context. Direct uniqueness, participant authorization, event projections, receipts, typing and private media mechanisms remain existing workspace behavior. Personal messaging is unavailable pending contact policy and participant-identity contracts; do not insert a fake organization or bypass authorization.

Current company-group creation validates active participants but lacks the new owner/admin-only creation restriction: Phase 5 blocker. Team/branch management uses Organization permissions; MEMBER does not receive creation rights. Custom/MANAGER team permissions require explicit review against the final owner/admin product rule. Platform grants never confer private chat/media/contact access.
