# Aurora Design System

Tailwind CSS 4 semantic tokens define background, surface, alternate surface, primary, muted text, border and sidebar. Light: #F7F8FC / #FFFFFF / #635BFF / #171A3A. Dark: #0E1020 / #17192B / #8178FF / #111326. Web screens use semantic utilities for surfaces, text, forms, tables and chat. Existing browser theme storage and System preference listener are retained.

Workspace components reuse Button/Card/Modal/Table/StatusBadge/IdentityDisplay/Empty/Error patterns. Modals retain focus trapping, Escape and focus return. Small screens use labeled stacked management rows and a focus-managed navigation modal. Role color is presentation only: violet Owner, indigo Admin, blue Manager, neutral Member.

Admin platform screen conversion belongs to Phase C and is not part of Phase B.
